# cfd-solver

A GPU-native, unstructured finite-volume CFD solver for arbitrary polyhedral meshes, with a discrete adjoint on GPU and a typed Python SDK.

**Status: pre-alpha.** Nothing runs yet. The plan, research and design are in [`docs/`](docs/):

- [Implementation plan](docs/PLAN.md)
- [State of the art, 2026](docs/research/state-of-the-art-2026-10.md)
- [Developer experience](docs/design/dx.html) and [UX mockup](docs/design/ux-mockup.html)

Design documents are currently in French; code and reference docs are in English.
