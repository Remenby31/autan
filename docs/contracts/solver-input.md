# Contract: solver input

The solver input is the document the SDK hands to the solver runtime `autan-run`: a case already planned against its mesh, every zone resolved, every value in SI. The runtime applies no unit conversion, default or resolution rule of its own. Schema identifier: `autan.solver-input/1`; the JSON Schema is generated by `autan schema solver-input`.

Producer: `autan prepare` / `autan.solver_input.build` (owner: CFD - SDK & contrats), only after a plan without errors; `autan prepare` reports the plan's warnings on stderr. Consumer: `autan-run` (owner: CFD - Noyau maillage).

## Invocation

```text
autan-run --input solver-input.json --runs DIR
```

`autan-run` creates `DIR/<run_id>/` as [results.md](results.md) specifies, writing `case.toml` (the `case.toml` text of the input, unchanged), its own `mesh-info.json`, `run.json`, `history.jsonl` and `solution.cgns`, with `identity` and `run_id` computed from its own commit. It prints the run directory path on one line of stdout.

| Exit | Meaning |
|---|---|
| 0 | The run ended `converged`, `completed`, `stopped` or `diverged`; the status is in `run.json`. |
| 1 | The run `failed`; `run.json` carries `E0704`. |
| 2 | The input cannot be run: invalid document (`E0705`, `data.path` names the key), mesh hash different from `mesh.sha256` (`E0203`), or no implementation of the physics, turbulence model, precision and device kind in this build (`E0706`). No directory is created; the diagnostics go to stderr as JSON in the shape of [case-schema.md](case-schema.md#diagnostics), with `fix` and `doc` taken from [`diagnostics.json`](diagnostics.json), as for every diagnostic the runtime writes. |
| 130 | Stopped by SIGINT or SIGTERM; the run is finalized as `stopped` with its solution. |

## Document

Every table rejects unknown keys; every key is present, `null` where it does not apply, and every tag (`schema`, `kind`, `law`, `model`) is written. Units are SI: m, s, kg, K, Pa, rad. Values a key's neighbours make meaningless must be `null`, values they require must not be; the JSON Schema encodes these rules.

| Key | Content |
|---|---|
| `schema` | `"autan.solver-input/1"` |
| `case` | `name`; `sha256` the case hash; `toml` the exact text to write as `case.toml` |
| `mesh` | `path` absolute path of the mesh file or polyMesh directory; `sha256` expected mesh hash ([mesh-info.md](mesh-info.md)), checked by the runtime |
| `precision` | `"fp32+acc64"` or `"fp64"` |
| `deterministic` | Bitwise-deterministic mode requested |
| `devices` | `kind` (`cpu`, `cuda`, `hip`) and `count` |
| `physics` | `kind` (`compressible`, `incompressible`); `turbulence`: `model`, `base` (DDES only: `sa` or `sst`), `wall_model` (WMLES only), `nu_tilde_ratio` (exactly for SA and DDES on SA), `intensity` and `viscosity_ratio` (exactly for SST and DDES on SST). DDES and WMLES require an unsteady `time`. |
| `freestream` | Closed state: `density` (kg/m³), `pressure` (Pa; 0 for incompressible), `temperature` (K; null for incompressible), `velocity` (m/s, mesh axes), `speed` (m/s), `viscosity` (dynamic, Pa·s); as given: `mach`, `re`, `ref_length` (m), `aoa` and `sideslip` (rad); turbulence state: `nu_tilde` (m²/s), `k` (m²/s²), `omega` (1/s), null when the model has none |
| `boundaries[]` | One entry per boundary zone with a condition (zones without faces and without condition are omitted): `zone` (MeshInfo name), `kind` as in [case-schema.md](case-schema.md#boundaries), and its values, required for its kind and null otherwise: `inlet` takes `total_pressure` (Pa) and `total_temperature` (K); `velocity-inlet` takes `velocity` (m/s); `outlet` takes `static_pressure` (Pa); `wall` may take `temperature` (K, isothermal; null is adiabatic); the other kinds take none. |
| `cell_zones[]` | One entry per cell zone: `zone`, `initial` (see [initial state](#initial-state)), `medium`: `{kind = "ideal-gas", name, gas_constant (J/(kg·K)), gamma, prandtl, viscosity = {law = "sutherland", mu_ref (Pa·s), t_ref (K), s (K)} or {law = "constant", mu (Pa·s)}}`, `{kind = "constant-density-fluid", name, density, viscosity}` or `{kind = "solid", name, density, specific_heat (J/(kg·K)), conductivity (W/(m·K))}` |
| `time` | `{kind = "steady", max_iterations, residual_orders}` or `{kind = "unsteady", steps, dt (s), cfl, average_from}` with exactly one of `dt` and `cfl` non-null and `average_from` null or below `steps` |
| `monitors[]` | `{kind = "forces", name, every, zones (boundary zone names), ref_area (m²) or null, ref_length (m) or null, moment_center (m)}` |

The freestream closure is that of [case-schema.md](case-schema.md#freestream): with `re`, ρ∞ = Re μ(T∞) / (V∞ L) and p∞ = ρ∞ R T∞; with `pressure`, ρ∞ = p∞ / (R T∞); V∞ = M √(γ R T∞); R = 8.314462618 J/(mol·K) divided by the molar mass. Turbulence at an inlet uses the ratios of `physics.turbulence` with the inlet's local ν and speed, as [case-schema.md](case-schema.md#turbulence) defines.

## Initial state

Each cell zone starts from the freestream pressure, temperature and velocity, closed with the zone's own medium, so zones of different gases or fluids start consistently:

- fluid zone, `initial = {kind = "fluid", density, pressure, temperature, velocity, nu_tilde, k, omega}`: ideal gas ρ = p∞ / (R_zone T∞); constant-density fluid ρ = its density, p = 0; ν = μ_zone(T∞) / ρ; `nu_tilde` = `nu_tilde_ratio` ν, k = 1.5 (`intensity` V∞)², ω = k / (`viscosity_ratio` ν), each null when the model has none;
- solid zone, `initial = {kind = "solid", temperature}`: T∞.
